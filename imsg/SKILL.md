# iMessage

## When to Use
- Habib minta cek iMessage dari PC
- Setup Phone Link
- Kirim notif via iMessage

## Process
1. Cek apakah Phone Link (Microsoft) terinstall & running
2. Kalo belum: install dari Microsoft Store
3. Pair iPhone via Bluetooth
4. Buka iMessage dari Phone Link UI
5. Kalo ga bisa diakses dari terminal: report ke Habib via Telegram

## Don't Do
- Ace ga bisa send/receive iMessage langsung — butuh bridge
- Jangan claim bisa kirim iMessage kalo bridge ga jalan

## Integration
- rich-messages — format output
- browser-automation — navigasi setup
