# Using Superpowers

**Rule:** Check for relevant skills BEFORE any action/response. Even 1% chance → invoke it.

## Priority
1. User explicit instructions (highest)
2. Superpowers skills
3. Default system behavior

## Process
1. Check process skills first (brainstorming, debugging)
2. Check implementation skills second
3. Announce: "Using [skill] to [purpose]"
4. If checklist exists, create TodoWrite tasks
5. Follow skill exactly

## Red Flags (thoughts that mean STOP)
- "Just a simple question" → Questions are tasks, check skills
- "Need context first" → Skills tell you HOW, check first
- "I remember this skill" → Skills evolve, re-read current version
- "Skill is overkill" → Use it anyway

## Platform Tools
Skills use tool names from your platform. Adapt as needed.

Deactivate: "skip skills" / "no skills this time"
